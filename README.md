# Ryouki v3

Ekstrak ZIP dan unggah folder berisi index.html ke Netlify. Tidak perlu build.

- MP3 lengkap yang diunggah disertakan sebagai assets/backsound.mp3.
- Autoplay dicoba saat masuk; jika diblokir browser, klik Masuk pada intro.
- Loop, mute/unmute asli, dan play/pause.
- Intro kucing pixel putih-pink dengan animasi tile dan background blur.
- Tombol Masuk / Lewati intro.
- Enam video YouTube, tanpa kategori Live.
- Musik dijeda saat video dibuka dan dilanjutkan setelah ditutup jika sebelumnya sedang diputar.

Edit music-config.js untuk mengganti audio. Edit index.html untuk teks, app.js untuk daftar video, style.css untuk tampilan. Logo pixel menggunakan SVG yang bisa diedit di kode.
